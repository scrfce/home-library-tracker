# ДомБиблиотека (HomeLibrary)

Простое веб-приложение для учёта домашней библиотеки и книг, которые вы одолжили друзьям, родным или коллегам.

> Статус: проектирование завершено, реализация ещё не начата (учебный проект, День 3).

## Проблема

Книги накапливаются, а часть из них уходит «погостить» к знакомым. Через пару месяцев уже никто не помнит, кому и когда была выдана книга, и она часто не возвращается. Блокноты, заметки и таблицы неудобны для поиска и не напоминают о возврате.

## Цели разработки

- создать удобный каталог домашней библиотеки с быстрым поиском;
- вести журнал выдачи книг: кому, когда и на какой срок выдана книга;
- снизить количество потерянных и забытых книг с помощью напоминаний о возврате;
- обеспечить удобную работу как на компьютере, так и на телефоне.

## Основные возможности

- регистрация, вход и приглашение читателей по ссылке;
- добавление, редактирование и удаление книг;
- каталог с поиском и фильтрацией по названию, автору, жанру, категории, тегам и статусу;
- оформление выдачи и возврата книг;
- список книг «на руках» с выделением просроченных;
- история выдач по книге и по получателю;
- напоминания о сроках возврата по электронной почте;
- запросы читателей на книги и список выданных им книг.

## Планируемые технологии

| Компонент | Технология |
| --- | --- |
| Язык и фреймворк | Python 3.12, Flask |
| База данных | SQLite (с возможностью перехода на PostgreSQL) |
| Работа с данными | SQLAlchemy |
| Интерфейс | HTML, CSS, JavaScript, шаблоны Jinja2 |
| Тестирование | pytest |
| Контроль версий | Git, GitHub |

## Роли пользователей

| Роль | Кратко |
| --- | --- |
| Владелец | Ведёт каталог, оформляет выдачу и возврат, видит историю и запросы |
| Читатель | Просматривает каталог, на который его пригласили, запрашивает книги, видит свои книги |
| Гость | Может только зарегистрироваться и войти |

Внешняя система: почтовый сервис, через который отправляются напоминания.
